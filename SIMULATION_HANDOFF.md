# Delta Crossroads Simulation Handoff

## Project Purpose

This repository contains the current Lovable implementation of:

"The Delta Crossroads: Balancing Adaptation, Mitigation, and Participation in Nigeria's Climate Crisis"

This is an existing educational simulation prototype.

The objective is to refine the experience into a professional, cinematic, scene-based simulation while preserving the existing simulation logic.

---

# Non-Negotiable Preservation Rules

Do not remove, simplify, or replace:

- simulation state management;
- decision consequence logic;
- evidence tracking;
- Strategy File system;
- branching/state transitions;
- ending resolution;
- causal debrief logic.

Visual redesign must consume the existing simulation state.

The experience layer should change.
The simulation logic should remain stable.

---

# Redesign Goal

Transform the current webpage-style simulation into:

A scene-based professional climate policy experience.

The learner should feel like they are inside a crisis-management situation, not navigating an application.

---

# Experience Principles

## Environment First

The environment and media establish:

- location;
- situation;
- emotional tone;
- important objects;
- narrative context.

The interface provides only the tools required to act.

## Scene-Based UX

Design scenes, not webpages.

Each scene should have:

- one meaningful purpose;
- one dominant action;
- clear cause and effect;
- progressive information disclosure.

## Cognitive Flow

Every moment should communicate:

1. What is happening?
2. What do I need to understand?
3. What can I do?
4. What changed because of my action?
5. What happens next?

# Current Technical Context

Framework:
React + TypeScript + Vite

Styling:
Tailwind CSS

The current application was generated with Lovable and contains functional simulation architecture.

---

# Implementation Approach

Before modifying code:

1. Analyse the existing architecture.
2. Identify reusable components.
3. Identify simulation-critical files.
4. Preserve state and consequence systems.

Do not perform a full rewrite.

Refine the experience layer incrementally.
